검수 기록

사후 판정 — 이 건을 문제 삼았는데, 확인해 보니 실제로는 결함이 없었습니까?
이 판정이 없으면 오탐률(M3)이 계산되지 않습니다. 「전부 반려」가 최적 전략이 되는 것을 막는 유일한 장치입니다.

이 문제, 이전 산출물에서 왔습니다

통과시킨 산출물에서 나중에 드러난 결함을 그때의 실행에 연결합니다. 이 연결이 유출률(M2)의 유일한 원천입니다.
같은 사건이 여러 실행을 통과한 경우 최초 통과 실행에만 유출로 계상됩니다. 반복 통과를 전부 세면 오래된 결함일수록 유출률이 부풀려집니다.

알림함 — 통보 기록

L3 실행 결과 · 에스컬레이션 · 치명 유출 · 자동 강등 · 승격 제안 · 명세 개정 제안 · 표본 검수 요청을 예외 없이 기록합니다. 기록은 추가만 가능하며 수정·삭제할 수 없습니다. [확인]은 확인 시각을 별도로 추가합니다.

월별 AI 실제 청구액

구독료와 API 사용료를 합친 전사 청구액입니다. 금액을 넣은 달은 추정 대신 이 금액을 쓰고, 비워 둔 달은 추정으로 계산합니다. 프로젝트별로 볼 때는 그 달 추정 비중으로 나눕니다.
