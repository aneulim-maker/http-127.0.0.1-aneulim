eulim AI 아바타 Q&A — 사용 안내
================================

[폴더 구조]
  eulim_avatar_qna.html   ← 이 파일을 브라우저로 열면 됩니다
  clips/                  ← 영상 파일을 넣는 폴더
    idle.mp4              ← 대기화면 (W3, 이미 포함됨)
    A1_opening.mp4        ← 자기소개 (W1 완성본을 여기에 넣으세요)
    ... (나머지 답변 클립)

[영상 추가하는 법]
  1. Flow에서 답변 클립을 만든다
  2. clips/ 폴더에 넣는다
  3. eulim_avatar_qna.html을 편집기로 열어 상단 CLIPS 목록에서
     해당 질문의 file:"" 안에 파일명을 적는다
     예)  file:"clips/B1_intro.mp4"
  4. 저장 후 브라우저 새로고침

[웹에 올리기 - 무료]
  GitHub Pages 또는 Netlify에 이 폴더를 통째로 올리면
  링크 하나로 누구나 볼 수 있습니다. (이력서/포트폴리오에 첨부)

[중요]
  - 파일명에 한글/공백 없이 영문으로 (예: D1_hire.mp4)
  - idle.mp4는 이미 들어있으니 바로 작동합니다
  - "준비중" 표시는 file이 비어있다는 뜻, 영상 넣고 파일명 적으면 사라집니다
